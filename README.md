# Eshak Pay 🫏

**Eshak Pay** — учебная информационная система электронных платежей.

Проект представляет собой упрощённую модель платёжной системы и реализует основные операции: регистрацию пользователей, авторизацию, работу со счетами, управление балансом, переводы между пользователями и историю операций.

> ⚠️ **Важно:** Eshak Pay является учебным проектом и не является настоящим банком или платёжным сервисом. Реальные денежные средства не обрабатываются.

## ✨ Возможности

- Безопасное хеширование паролей с Argon2id

## 💳 Переводы

Перевод между пользователями выполняется как транзакционная операция.

Для запросов переводов используется **Idempotency-Key**, который позволяет избежать повторной обработки одной и той же операции при повторной отправке запроса.

Запросы на перевод и успешно выполненные финансовые операции хранятся отдельно.

## 📊 История операций

Пользователь может просматривать историю своих финансовых операций.

В истории отображаются входящие и исходящие переводы, а также первоначальное зачисление средств.

## 🔐 Авторизация

Eshak Pay использует серверные сессии вместо JWT.

После успешной авторизации сервер создаёт случайный session token, а в PostgreSQL хранится его хеш.

Токен передаётся клиенту через HTTP-only cookie.

Пароли пользователей не хранятся в открытом виде и хешируются с использованием Argon2id.

## 🗄 База данных

Проект использует PostgreSQL и SQL-запросы без ORM.

Основные сущности:

```text
users
sessions
accounts
cards
transactions
postings
transfer_requests
```

Финансовые проводки используют знаковую модель:

- списание — отрицательная сумма;
- зачисление — положительная сумма.

## 🚀 Запуск локально

### Требования

- Go 1.22+
- PostgreSQL

### 1. Клонировать репозиторий

```bash
git clone https://github.com/rabotyaga-ctrl-v/eshak-pay.git
cd eshak-pay
```

### 2. Настроить переменные окружения

Создать файл `.env`:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=eshak_pay
DB_USER=eshak_app
DB_PASSWORD=your_password
DB_SSLMODE=disable
```

### 3. Создать базу данных

Создать PostgreSQL database и применить SQL-схему проекта.

### 4. Установить зависимости

```bash
go mod tidy
```

### 5. Запустить сервер

```bash
go run ./cmd/server
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8080
```
